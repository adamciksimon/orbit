# Orbit

Trusted HTTPS domains for local dev servers, e.g. `https://app.local` → `http://localhost:3000`.

| Folder | What |
| --- | --- |
| [`orbit-app`](orbit-app) | The native macOS app (Swift/SwiftUI). See its README for building and releasing. |
| [`orbit-web`](orbit-web) | The product site (Nuxt), deployed to [orbit.simon-studio.cc](https://orbit.simon-studio.cc) via Cloudflare Workers. |
